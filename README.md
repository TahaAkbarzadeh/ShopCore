# ShopCore

ShopCore is a backend-focused e-commerce project built with ASP.NET Core and designed using Clean Architecture principles.

The project aims to provide a scalable and maintainable foundation for an online shopping platform, featuring product and category management, inventory control, user authentication, shopping cart functionality, order processing, and payment simulation.

## Tech Stack

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Clean Architecture
- JWT Authentication

## Main Features

- Product and Category Management
- Inventory Management
- User Authentication and Authorization
- Shopping Cart
- Order Management
- Payment Simulation
- RESTful API Design

## Project Goals

This project is developed to strengthen backend engineering skills, practice software architecture principles, and implement real-world e-commerce business logic.
